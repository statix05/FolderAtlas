# FolderAtlas

Open Source аналог File List Export для macOS: превращает любую папку или диск в **карту** — структурированный каталог файлов с богатыми метаданными, который можно просматривать, фильтровать, сохранять, сравнивать и экспортировать.

- **Платформа:** macOS 15+ (собрано и проверено на macOS 27)
- **Стек:** Swift 6, SwiftUI + AppKit там, где без него нельзя (Services, Quick Look)
- **Лицензия:** MIT (`LICENSE`)

## Возможности

- **Сканирование** папки или диска: имя, тип, расширение, абсолютный и относительный путь, логический размер, занятое на диске место, даты создания/изменения, Finder-теги, флаги (скрытый / симлинк / пакет), агрегаты папок (прямые элементы, вложенные, суммарный размер).
- **Обогащение по запросу**: SHA-256 (стриминг), размеры/формат/цветовая модель/EXIF/GPS картинок, длительность/разрешение/кодек/битрейт/частота/каналы видео и аудио.
- **Просмотр** таблицей (сортировка, настройка колонок, множественное выделение) или деревом с агрегатами папок; поиск и комбинируемые фильтры (тип, расширение, размер, даты, теги, скрытые, симлинки, ошибки, iCloud, доступность источника).
- **Сохранение карт** в локальную библиотеку (`~/Library/Application Support/FolderAtlas/Snapshots/*.foldermap`) и открытие **без исходного диска**. Карта — снимок метаданных, не резервная копия содержимого.
- **Сравнение** двух снимков одного источника: добавленные, удалённые, изменённые и предположительно перемещённые/переименованные (контрольная сумма → высокая достоверность, размер + дата создания + расширение → средняя).
- **Дубликаты** по содержимому: группировка по размеру, SHA-256 только для кандидатов. Удаление дубликатов сознательно не входит в первую версию.
- **Экспорт** в CSV, TSV, JSON, HTML (автономная страница с поиском и миниатюрами), Markdown, PDF (постраничные таблицы) и **настоящий XLSX** (полноценный OpenXML-пакет, не «CSV с расширением .xlsx»).
- **Finder**: ПКМ по папке → **Службы → Составить карту папки**. Работает и при закрытом приложении, поддерживает несколько выделенных папок (окно на каждую). Также — перетаскивание на окно и на иконку в доке.

Приватность: всё локально, без аккаунта, облака и телеметрии. Сканирование не изменяет и не удаляет файлы; плейсхолдеры iCloud никогда не скачиваются.

> **Известные проблемы** честно ведутся в [журнале изменений](CHANGELOG.ru.md) (раздел «Известные проблемы» невыпущенной версии) — сейчас там: сброс порядка столбцов при их включении/выключении (признано, отложено) и «размер на диске», который может показывать меньше реального размера, пока чинится расчёт.

## Сборка

Нужны Xcode 16+ и [xcodegen](https://github.com/yonaskolb/XcodeGen) (`brew install xcodegen`).

```bash
xcodegen generate
xcodebuild -project FolderAtlas.xcodeproj -scheme FolderAtlas -configuration Debug build
```

Релизная сборка:

```bash
xcodebuild -project FolderAtlas.xcodeproj -scheme FolderAtlas -configuration Release build CONFIGURATION_BUILD_DIR=build
# приложение: build/FolderAtlas.app
```

Подпись ad-hoc, аккаунт разработчика не нужен.

## Установка Finder Services

1. Скопируйте `FolderAtlas.app` в `/Applications`.
2. Запустите приложение один раз (или выполните `/System/Library/CoreServices/pbs -flush`).
3. В Finder: ПКМ по папке → **Службы** → **Составить карту папки**. Если пункта нет — включите его в «Системные настройки → Клавиатура → Сочетания клавиш → Службы → Файлы и папки».
4. Название сервиса локализовано: «Составить карту папки» (ru) / *Make Folder Map* (en).

Первое сканирование защищённых locations (Рабочий стол, Документы и т.п.) вызовет стандартный запрос доступа; для системных папок удобно выдать **Полный доступ к диску** (Конфиденциальность и безопасность).

Приложение намеренно **не sandbox** (открытая поставка вне App Store): переданные сервисом URL доступны напрямую, security-scoped bookmarks не нужны.

## Тесты

```bash
xcodebuild -project FolderAtlas.xcodeproj -scheme FolderAtlas test
```

Покрытие: сканер (Unicode-имена, скрытые файлы, пакеты, симлинки и защита от циклов, недоступные папки, глубокая вложенность, пустые папки, отмена, события прогресса), roundtrip хранилища, фильтры, diff (включая эвристику перемещений), дубликаты, CSV-экранирование и защита от формульной инъекции, ZIP-писатель (проверка `unzip -t`), структура XLSX, автономность HTML, вывод PDF и JSON.

## Архитектура

См. `ARCHITECTURE.ru.md`. Коротко: модели → сканер (параллельный BFS с ограниченным параллелизмом) → хранилище (NDJSON-снимки) → поиск/фильтры → сравнение → экспорт → системная интеграция → SwiftUI UI.

## Зависимости

Никаких сторонних. Только системные фреймворки: Foundation, SwiftUI, AppKit, ImageIO, AVFoundation, CryptoKit, CoreText/CoreGraphics, Compression. XLSX-писатель — собственная минимальная реализация в репозитории.
