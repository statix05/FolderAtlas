# Журнал изменений

## 1.2.0-beta.1 — 04.11.2026 (бета; очередь v1.2.0 продолжается: ясность столбцов, глобальное меню, контекст-меню, .DS_Store, подсветка кеша, Nerd Font)

### Известные проблемы (честный список открытых багов)

- **Порядок столбцов сбрасывается.** Ручная перестановка столбцов (например, «Тип» на первое
  место) не сохраняется при включении/выключении столбцов — порядок откатывается к
  сохранённому/дефолтному. Признано владельцем, осознанно отложено, будет исправлено.
- **«Размер на диске» может показывать меньше реального размера файла.** В реальности это
  невозможно (занятое место ≥ логического размера); расчёт проверяется. Вместе с фиксом
  планируется объединённый отключаемый столбец «Размер / На диске».
- **Finder-сервис проверяется только по ручному чек-листу.** Регистрация сервиса
  верифицируется программно (`pbs -flush` + дескриптор), но полный сценарий
  Finder → ПКМ → Службы (холодный и тёплый запуск приложения) проверяется владельцем
  вручную, инструкция в README (раздел «Finder-сервис»).
- **Иконки строк — временные SF Symbols.** Подключение бандл-шрифта Nerd Font (глифы типов
  строк) в очереди; маркер несохранённой карты — временный астериск.

### Планируется (очередь, согласованная с владельцем)

- Дистрибуция через Homebrew: формула + bottle (`brew install --cask folderatlas`)
- Ясность столбцов: «Размеры» → «Разрешение», полные подписи в меню столбцов
  («Элементов в корне папки», «Вложенных файлов в папке»), убрать лишний «Размер папки»,
  добавить «Путь абсолютный» рядом с «Путь».
- Глобальное меню macOS со всеми настройками и горячими клавишами
  (App/File/Edit/View/Window/Help) — требование владельца по конвенциям macOS.
- Контекстное меню строки: «Переместить в корзину», «Скопировать путь для Terminal»
  (POSIX-экранирование).
- Отдельный переключатель «.DS_Store» (независимый от показа скрытых, по умолчанию выключен).
- Жёлтая подсветка файлов кеша/временных файлов.
- Бандл-шрифт Nerd Font для иконок строк.

### Исправлено после v1.1.0

- **Сортировка не работала вовсе.**
  *Было:* клик по заголовку двигал индикатор, но строки не перестраивались — два
  конкурирующих механизма гасили друг друга (автоматический цикл AppKit через
  `sortDescriptorPrototype` и программная перезапись `sortDescriptors` при каждой синхронизации).
  *Стало:* один явный механизм — кастомный `NSTableHeaderView` отличает клик от драга и ведёт
  цикл сортировки; сортировка строится по предвычисленным ключам (схема снимков v2), за счёт
  чего мгновенна и на миллионах строк (500 000 строк: 8.22 с → 1.59 с).
- **Приложение зависало на 20+ минут после второго клика сортировки.**
  *Было:* SwiftUI `Table` вис в `SwiftUI._preparedRowViewForRow` на больших картах.
  *Стало:* вью заменена на нативный `NSOutlineView` — сортировка и прокрутка отзывчивы
  на очень больших картах.
- **Крэш SIGABRT (AttributeGraph) рядом с таблицей.**
  *Было:* opacity-анимация на содержимом таблицы роняла приложение (инцидент 609EF7EF,
  macOS 27.2).
  *Стало:* анимации вокруг таблицы убраны, перезагрузки детерминированные.
- **После рефакторинга пропали заголовки столбцов и прокрутка.**
  *Было:* промежуточная версия клала «голый» `NSTableView` без скролл-вью.
  *Стало:* таблица всегда `documentView` внутри `NSScrollView` — заголовки и прокрутка
  на месте и переживают изменение размеров окна.
- **Иконки папок/файлов разного размера или исчезали в узких столбцах.**
  *Было:* `NSStackView` при нехватке места жал иконку до нуля, после прокрутки иконки
  пропадали снова.
  *Стало:* у иконки фиксированные обязательные констрейнты; обрезается текст, а не иконка.
- **Клик по границе столбца сортировал вместо изменения ширины.**
  *Было:* позиции разделителей считались вручную без учёта межколоночного зазора (здесь
  17 pt, а не 3!) — расчёт уезжал от колонки к колонке, и видимые границы попадали в зону
  сортировки.
  *Стало:* граница определяется по родной геометрии таблицы `rect(ofColumn:)`; граница и
  зазор — ресайз/автофит, сортирует только тело столбца.
- **Двойной клик по границе не подгонял ширину столбца.**
  *Было:* ставка на делегат AppKit `tableView(_:sizeToFitWidthOfColumn:)` — как показал
  лог, на macOS 27 он не вызывается вообще.
  *Стало:* заголовок сам детектит двойной клик по границе (`clickCount ≥ 2`) и подгоняет
  столбец СЛЕВА от границы, как в Excel. Замер идёт вне главного потока (без фризов на
  больших картах), результат не режет ни ячейки, ни заголовок:
  ширина = max(самая длинная ячейка + запас, ширина локализованного заголовка + отступ).
- **Каждый холодный запуск открывал пустое окно; при тестах плодились экземпляры.**
  *Было:* запуск без аргументов всегда открывал новый пустой черновик.
  *Стало:* холодный старт открывает последнюю сохранённую карту; запущенный экземпляр
  переиспользуется.
- **Добавление папки открывало карту в новом окне.**
  *Было:* каждая новая папка — новое окно.
  *Стало:* карта появляется в ТОМ ЖЕ окне (и при перетаскивании, и через Finder-сервис);
  при выборе нескольких папок первая открывается на месте, остальные — в отдельных окнах.
- **Несохранённые карты терялись при переключении или закрытии окон.**
  *Было:* черновик жил внутри сессии своего окна — переключение на сохранённую карту или
  закрытие окна его уничтожало.
  *Стало:* несохранённые карты живут в библиотеке приложения (в памяти): переживают
  переключение карт и закрытие окон до выхода из приложения; сохранение превращает черновик
  в обычную карту; повторное открытие той же папки переиспользует существующий черновик.
  В сайдбаре — секция «Несохранённые» с маркером-астериском (звезда отклонена — читается
  как «избранное»).
- **Переключение видимости столбцов дублировало колонки (два «Имя») и раздувало первую.**
  *Было:* пересборка удаляла все колонки и добавляла заново, но `NSOutlineView` отказывается
  удалять свою outline-колонку через `removeTableColumn:` (AppKit сам пишет
  *"cannot remove outlineTableColumn"*), старая outline-колонка переживала разборку,
  оставалась первой, раздувалась, а повторно добавленная копия дублировала её;
  даже `outlineTableColumn = nil` не отпускает ссылку.
  *Стало:* отдельный `TableColumnRebuilder` перекидывает outline-роль на выживающую колонку,
  диффит набор столбцов, восстанавливает порядок через `moveColumn` и позволяет вообще
  скрыть столбец «Имя» (раньше было невозможно). Покрыто пятью регресс-тестами
  на реальном `NSOutlineView`.

## 1.1.0

- Сортировка с переключателем «Папки сверху» и сохранением состояния сортировки (схема v2).
- Иконка приложения (светлая/тёмная), обновлённый оверлей.
- Finder-сервис: ПКМ по папке → «Создать карту папки» выгружает готовый XLSX рядом с папкой
  даже без запущенного приложения (headless-режим сервиса).
- Производительность: пересборка больших карт вне главного потока; бенчмарк 500 000 строк:
  8.22 с → 1.59 с.

## 1.0.0

- Первый релиз: рекурсивное сканирование папок в «карту» метаданных, просмотр таблицей и
  деревом, поиск и комбинируемые фильтры, обогащение метаданными (контрольные суммы,
  EXIF/GPS изображений, данные медиа), библиотека снимков (сохранение/открытие без
  исходного диска), сравнение снимков (добавлено/удалено/изменено/эвристика перемещений),
  поиск дубликатов (группировка по размеру → SHA-256), экспорт (CSV, TSV, JSON, HTML,
  Markdown, PDF, XLSX), интеграция с Finder (Службы), локализация ru/en.
